# 💻 Loan Analysis Report Dashboard
# 📌 Overview
# This project presents an interactive Power BI dashboard designed to analyze loan data and provide insights into loan applications, funding, and performance. It enables stakeholders to track key metrics, identify trends, and make data-driven decisions.

# 🎯 Objectives
# Analyze loan applications, funding, and performance
# Compare key metrics like loan amount, interest rate, and DTI
# Identify trends across regions and categories
# Enable data-driven financial decision-making

# 📊 Dashboard Features
# 🔹 Key KPIs
# Total Loan Applications
# Total Loans Funded
# Total Loan Amount Issued
# Average Interest Rate
# Average DTI Ratio
# 🔹 Visualizations
# Line/Area Charts → Trend analysis
# Map Charts → Geographic insights
# Donut & Tree Maps → Category distribution
# Tables → Detailed loan-level analysis
# 🔹 Interactivity
# Slicers (State, Grade, Loan Type)
# Drill-down functionality

# 📈 Key Insights
# Identified patterns in loan applications and funding trends
# Analyzed regional distribution of loan demand
# Evaluated loan quality and performance
# Highlighted key factors influencing loan outcomes

# 🛠 Tools & Technologies
# Power BI
# Excel
# DAX
# Data Modeling
